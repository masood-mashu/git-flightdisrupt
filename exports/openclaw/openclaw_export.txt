# Tools

## baggage-sla-tracker
Tracks delayed baggage transit days against Montreal Convention compensation threshold

**Parameters:**
- `delayed_days` (string) (required) — Number of days baggage has been delayed in transit

## eu261-compensation-calculator
Calculates EU261 statutory compensation eligibility in Euros based on flight distance and delay duration

- `delay_data_json` (string) (required) — JSON string containing delay_minutes, distance_km, and extraordinary_circumstance (bool)

Evaluates candidate rebooking flights to ensure departure within 12 hours of canceled flight

**Parameters:**
- `rebooking_data_json` (string) (required) — JSON string containing candidate_departure_offset_hours
